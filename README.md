# NShieldOps

NShieldOps is a SOC dashboard and monitoring project built with a vanilla HTML/CSS/JavaScript frontend and a Node.js/Express backend.

## Features
- Dashboard UI
- Authentication flow
- Monitoring and asset tracking
- Event/alert visualization
- API endpoints for backend operations

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Hosting: Render (for prototype/demo deployment)

## Project Structure
- `public/` - frontend files
- `server.js` - Express backend
- `package.json` - project scripts and dependencies

## Run locally
```bash
npm install
npm start
